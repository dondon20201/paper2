## Part A — Abstract (replace the STUB; ~220 words). USE THIS TEXT VERBATIM (Cowork-authored), except swap each numeral for its guarded `V$` object where one exists:

> Confidence in one's own judgments correlates across cognitive domains, a pattern usually read as evidence for domain-general metacognitive ability. But "confidence" conflates two separable quantities: its LEVEL — a person's average confidence, or set-point — and its INFORMATIVENESS, the metacognitive sensitivity with which confidence discriminates correct from incorrect responses. Because level is measured far more reliably than sensitivity, a naive comparison of their cross-domain correlations manufactures an apparent level-over-sensitivity advantage even when none exists. Using a preregistered, reliability-corrected estimator validated by simulation before it touched the data, we ask which component is domain-general in a four-domain confidence study (Lund et al., 2025). Confidence level generalizes strongly across domains (ρ_level = 0.42). Corrected metacognitive sensitivity also correlates across domains (ρ_sens = 0.31, 95% CI excluding zero) — it is not domain-specific. The level-minus-sensitivity gap that a strong dissociation account predicts is 0.11, with a 95% CI that does not exclude zero; the same analysis without correction would have "confirmed" a dissociation (raw gap 0.20, excluding zero). A non-ipsative multilevel decomposition and an external robustness tier across four Confidence Database studies reproduce the pattern: level travels, while the dissociation does not survive attenuation-aware analysis. Apparent dissociations between confidence components in metacognition are, in substantial part, a measurement-reliability artifact.

## Part B — Introduction (replace the STUB; ~5 paragraphs). Draft to this paragraph plan; measurement-lens throughout:
1. **The phenomenon and the standard reading.** Metacognitive confidence correlates across domains; this is widely taken as evidence for a domain-general metacognitive faculty. Set up why that matters (a general "self-monitoring" capacity vs. domain-specific skills).
2. **The conflation.** "Confidence" is not one thing: LEVEL/set-point (how high you run the dial) vs. INFORMATIVENESS/sensitivity (how well confidence tracks accuracy). These can dissociate in principle, and a domain-general *bias* (shared set-point) is a very different claim from domain-general *skill* (shared sensitivity). Prior work has often not separated them cleanly.
3. **The measurement trap (the paper's pivot).** Level is measured near-perfectly; sensitivity (AUROC2) is measured poorly and is trial-count-bound. A difference between two correlations is biased upward when one variable is measured much more reliably — so a raw level-vs-sensitivity contrast will *manufacture* an apparent dissociation under a true null. This is the central methodological hazard the paper is built around.
4. **This paper's approach.** A from-scratch, preregistered, reliability-corrected framework: components defined and validated in simulation (recovery + separability) before any cross-domain quantity is computed; d′-partialing forced by the gate; a single mechanically-chosen confirmatory pair; descriptive, multilevel, and external-database tiers as robustness, each with attenuation-aware yardsticks; a firewall between building the measurement layer and testing the thesis. State plainly up front that a null or partial dissociation is an acceptable, reportable outcome — the design is powered to detect a substantial gap, not a small one.
5. **Contributions list (explicit).** (i) a validated two-component measurement framework with a recovery/separability gate; (ii) a preregistered, reliability-corrected confirmatory test in Lund et al. (2025); (iii) a non-ipsative multilevel decomposition that avoids the mean-subtraction artifact; (iv) an external robustness tier across four Confidence Database studies with simulated null references. End on the one-sentence thesis: what looks like a level-over-sensitivity dissociation is, once measurement reliability is handled honestly, largely absent as a *distinguishable* effect — while confidence level itself clearly generalizes.

## Part D — Limitations (replace the STUB with prose; every standing item must appear). USE THIS TEXT (Cowork-authored), guarding numerals via `V$`:

> Several limitations bound these conclusions. First, the confirmatory test is powered to detect only a substantial dissociation: at a true gap of 0.4 the corrected test excludes zero roughly 60% of the time, so the null gap we report is "not excluded" rather than evidence of no dissociation — the design cannot distinguish a true null from a small gap it is underpowered to find. Second, metacognitive sensitivity is weakly measured everywhere in these data (split-half AUROC2 reliability far below that of confidence level); we therefore present disattenuation only as a range, never as a corrected point estimate, and treat the reliability asymmetry as a systematic feature rather than a nuisance to be fully removed. Third, the multilevel Δ_ICC is a boundary result: a Δ_ICC of zero sits at the very edge of its interval, within Monte-Carlo error of the bound, so we do not claim a zero-exclusion. Fourth, the confirmatory test rests on a single dataset and a single 200/200-trial domain pair (memory × vision); the other pairs are explicitly descriptive. Fifth, the external cross-domain evidence rests on a single small study (Arbuzova_unpub_3, n = 40) that clears its simulated null reference only narrowly (margins 0.046 and 0.020), and the smaller margin shrinks to about 0.008 under an independently constructed null simulator — so this replication is directional, not decisive; the remaining external pairs are within-vision task pairs or a condition pair and test task-generalization, not cross-domain generality. Sixth, the null-reference simulator matches each study's reliabilities and means but not higher moments, and uses fixed per-task accuracy with equally spaced latent thresholds. Seventh, the Confidence-Database disattenuation applies AUROC2 reliabilities to the d′-partialed residual, whose reliability is not identical to that of raw AUROC2. Eighth, first-order sensitivity (d′) is itself poorly measured outside the memory domain, and the multilevel resolution slope is not d′-partialed (the residual confound is quantified, not removed). Finally, gamma was excluded as a sensitivity measure because it leaked the set-point in recovery simulation, and we treat the meta-d′/M-ratio family as secondary; no meta-analytic pooling is performed across the heterogeneous Confidence-Database studies.
